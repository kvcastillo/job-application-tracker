HireTrackr

HireTrackr is a job application tracking web app with authentication. It allows users to manage and organize their job applications in one place. 

Features
• User authentication (register/login)
• Create job applications
• View all applications in a dashboard
• Edit existing applications
• Delete applications
• Simple and responsive UI

Tech Stack
• Frontend: React / Next.js (edit as needed)
• Backend: Node.js / Express (if applicable)
• Database: MongoDB / Firebase / etc.
• Authentication: JWT / Session-based auth
• Styling: Tailwind CSS (if used)

How It Works
1. Create an account using any username and password

2. Log in using your credentials

3. Add a new job application via “New Application”

4. View all applications in the dashboard

5. Edit or delete applications as needed
